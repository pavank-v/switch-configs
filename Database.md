Useful psql commands worth knowing.

```
\l              list databases
\c dbname       connect database

\dt             list tables
\d table        inspect table
\d+ table       detailed inspect

\du             list users/roles
\dn             list schemas
\di             list indexes

\x              expanded output
\timing         query timings
\conninfo       connection details

\e              edit query in $EDITOR
\! command      run shell command

\?              psql help
\h SELECT       help for SQL SELECT
\q              quit
```
